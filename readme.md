# Game Character Animation Selector

## Overview
This is a web-based game character animation selection project that allows users to choose different animations for a game character using a dropdown menu.

## Features
- Interactive animation selection dropdown
- Supports multiple character animations including:
  - Idle
  - Run
  - Jump
  - Ko (Knockout)
  - Punch

## Technologies Used
- HTML5
- JavaScript
- Canvas API

## Setup
1. Clone the repository
2. Open `index.html` in a modern web browser
3. Use the dropdown to select different character animations

## File Structure
- `index.html`: Main HTML file with animation selector
- `script.js`: JavaScript file handling animation logic
- `style.css`: Styling for the game interface
- `favicon.ico`: Project favicon

## How to Use
1. Select an animation from the dropdown menu
2. Watch the character animate based on your selection
